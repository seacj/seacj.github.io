Git hooks是什么

Git Hooks就是那些在Git执行特定事件（如commit、push、receive等）后触发运行的脚本（这个脚本可以是shell、python、Ruby等等）。可以类比成一个触发器，当监听到某种事件时，就会自动触发，并执行脚本。
